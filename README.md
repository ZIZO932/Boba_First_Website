# My first Boba website

My first website, made during a Hack Club workshop. It's a small page about boba tea, built with HTML and CSS while I was learning the basics.

## Open it

Download the repo and open `index.html` in a browser. There's nothing to install.

- [index.html](index.html) — the page content
- [style.css](style.css) — the styling
- [g.png](g.png) — the image used on the page

I made a second version later: [Boba Second Website](https://github.com/ZIZO932/Boba_Second_Website).
